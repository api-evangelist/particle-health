## API Reference
- [Getting Started](https://docs.particlehealth.com/reference/getting-started.md)
- [Generate a JSON Web Token (JWT)](https://docs.particlehealth.com/reference/get_auth-1.md): Generate a JSON Web Token (JWT)
- [Submit Patient](https://docs.particlehealth.com/reference/post_api-v2-patients.md): Registers a patient's demographics in Particle's system and generates a unique Particle Patient ID (PPID) for use in subsequent API operations.
- [Get Patient](https://docs.particlehealth.com/reference/get_api-v2-patients-id.md)
- [Search Patient](https://docs.particlehealth.com/reference/post_api-v2-patients-search.md)
- [Delete Patient](https://docs.particlehealth.com/reference/delete_api-v2-patients-id.md)
- [List Patients](https://docs.particlehealth.com/reference/get_api-v2-patients.md)
- [Create Query](https://docs.particlehealth.com/reference/post_api-v2-patients-particle-patient-id-query.md): Starts a one‑time query for this Particle Patient ID.
- [Get Query Status](https://docs.particlehealth.com/reference/get_api-v2-patients-particle-patient-id-query.md): Returns the current state and timestamps for the most recent (or specified) query for a patient.
- [Get FHIR® Datasets](https://docs.particlehealth.com/reference/get_api-v2-patients-particle-patient-id-fhir.md): Returns a FHIR® Bundle with paging and incremental sync.
- [Get FHIR® Resources By Type](https://docs.particlehealth.com/reference/get_api-v2-patients-particle-patient-id-fhir-type.md): Returns a paged FHIR® Bundle for a specific resource type.
- [Get FHIR® Resource By ID](https://docs.particlehealth.com/reference/get_api-v2-patients-particle-patient-id-fhir-type-id.md): Returns a single FHIR® resource by type and ID.
- [Collect Flat Datasets](https://docs.particlehealth.com/reference/get_api-v2-patients-particle-patient-id-flat.md): **Filter Options:**  **By Domain:** Add the domain name directly as a query parameter (no value needed). You can combine multiple domains. For example: - `?ALLERGIES` - Filter for allergies only - `?ENCOUNTERS&MEDICATIONS` - Filter for encounters and medications Available domains: `AI_CITATIONS`, `AI_OUTPUTS`, `ALLERGIES`, `COMPOSITIONS`, `COVERAGES`, `DOCUMENT_REFERENCES`, `ENCOUNTERS`, `FAMILY_MEMBER_HISTORIES`, `IMMUNIZATIONS`, `LABS`, `LOCATIONS`, `MED_FILLS`, `MEDICATIONS`, `ORGANIZATIONS`, `PATIENTS`, `PRACTITIONERS`, `PROBLEMS`, `PROCEDURES`, `RECORD_SOURCES`, `SOCIAL_HISTORIES`, `SOURCES`, `TRANSITIONS`, `VITAL_SIGNS`  **By Specific Resource:** Use the `resource_type` and `resource_id` query parameters together to retrieve a single resource by ID (documented below).
- [Get CCDA files](https://docs.particlehealth.com/reference/get_api-v2-patients-particle-patient-id-ccda.md): Download a zip file as application/octet-stream or single file with content type set to the file's content type
- [Create Patient Subscriptions](https://docs.particlehealth.com/reference/post_api-v1-patients-particle-patient-id-subscriptions-1.md): Adds subscriptions for a single patient.
- [Create Subscriptions for multiple Patients](https://docs.particlehealth.com/reference/post_api-v1-patients-subscriptions-1.md): Subscribe a batch of patients to Signal monitoring in a single API call.
- [List Patient Subscriptions ( optional by given type )](https://docs.particlehealth.com/reference/get_api-v1-patients-particle-patient-id-subscriptions-1.md): Lists subscriptions; optional type filter.
- [Delete Patient Subscriptions](https://docs.particlehealth.com/reference/delete_api-v1-patients-particle-patient-id-subscriptions-1.md): Deletes subscriptions of a given type for the patient.
- [Trigger Sandbox Workflow](https://docs.particlehealth.com/reference/post_api-v1-patients-particle-patient-id-subscriptions-trigger-sandbox-workflow-1.md): Triggers sandbox webhook notification events for testing.
- [Patient Provider Map](https://docs.particlehealth.com/reference/patient-provider-map.md): Returns the set of healthcare organizations associated with given patient across Particle's network. Each entry represents an endpoint organization enriched with directory information (NPI, address, managing organization). Returns an empty `providers` array if no records are found.This endpoint requires the Patient Provider Map feature to be enabled for your project. Reach out to your Particle Health representative to get set up.
- [Submit Document](https://docs.particlehealth.com/reference/post_api-v1-documents-1.md): Uploads a document (e.g., CCDA, discharge summary) with metadata for ingestion and linkage.
- [Get Patient Documents](https://docs.particlehealth.com/reference/get_api-v1-documents-patient-id-1.md): Lists documents associated with a patient (internal or Particle Patient ID).
- [Get Document](https://docs.particlehealth.com/reference/get_api-v1-documents-id-1.md): Retrieves a single document and its metadata.
- [Delete Document](https://docs.particlehealth.com/reference/delete_api-v1-documents-id-1.md): Removes a document.
- [List Project Notifications](https://docs.particlehealth.com/reference/notifications_listnotifications2.md): Lists Notifications for a specific Project.
- [Create Project Notification](https://docs.particlehealth.com/reference/notifications_createnotification2.md): Creates a Notification under a specific Project.
- [Search Projects](https://docs.particlehealth.com/reference/projects_searchprojects.md): Searches Projects by simple field filter
- [Search Service Accounts](https://docs.particlehealth.com/reference/serviceaccounts_searchserviceaccounts.md): Searches Service Accounts by simple field filter
- [List Batches](https://docs.particlehealth.com/reference/get_api-v1-batches.md): Lists batch jobs with state, type, and counts.
- [Get Batch](https://docs.particlehealth.com/reference/get_api-v1-batches-batch-id.md): Returns batch metadata, progress, and results summary.
- [Create Batch](https://docs.particlehealth.com/reference/post_api-v1-batches-batch-type.md): Starts a batch job of type CCDA, FHIR®_R4, FLAT, or DELTAS with demographics or Particle IDs.
- [Get HL7v2 Message](https://docs.particlehealth.com/reference/get_hl7v2-message-id-1.md): Returns a single HL7v2 message
- [Get HL7v2 Messages by Patient](https://docs.particlehealth.com/reference/get_hl7v2-patient-particle-patient-id-1.md): Returns HL7v2 messages tied to the patient.
- [Alternative and Legacy Query Flows](https://docs.particlehealth.com/reference/legacy-query-flows.md)
- [Submit Flat Patient](https://docs.particlehealth.com/reference/post_flat-1.md): Initiates a Flat query for a specific patient using demographics
- [Get Flat Patient](https://docs.particlehealth.com/reference/get_flat-id-1.md): Retrieve the status of a flat query
- [Collect Flat Datasets](https://docs.particlehealth.com/reference/get_flat-id-collect-data-1.md): Query parameter filtering is not included by default. If you require access, please contact support@particlehealth.com.
- [Get Flat Resource](https://docs.particlehealth.com/reference/get_flat-patient-id-resource-type-resource-id-1.md): Returns a specific Flat resource
- [Create Patient](https://docs.particlehealth.com/reference/post_r4-patient-1.md): Creates a FHIR® R4 Patient resource.
- [Query Patient](https://docs.particlehealth.com/reference/post_r4-patient-patient-id-query-1.md): Starts a FHIR® query against the patient.
- [Retrieve all resources related to a patient.](https://docs.particlehealth.com/reference/get_r4-patient-patient-id-everything-1.md): Returns a FHIR® Bundle of all resources related to the patient with paging and date filters.
- [Retrieve the status of the most recent query run on a Patient.](https://docs.particlehealth.com/reference/get_r4-patient-patient-id-query-1.md): Returns status of the most recent query for this FHIR® patient.
- [Search for FHIR® resources.](https://docs.particlehealth.com/reference/get_r4-resource-type-1.md): Searches a resource type (Patient, Encounter, etc.) scoped by patient.
- [Read a specified FHIR® resource.](https://docs.particlehealth.com/reference/get_r4-resource-type-resource-id-1.md): This endpoint is not included by default. If you require access, please contact support@particlehealth.com.
- [Submit Deltas Query](https://docs.particlehealth.com/reference/post_deltas-1.md): Initiates a query with purpose of use, hints, specialties, etc.
- [Get Deltas Query Status](https://docs.particlehealth.com/reference/get_deltas-particle-patient-id-1.md)
- [Get Deltas Flat Resource](https://docs.particlehealth.com/reference/get_deltas-flat-particle-patient-id-resource-type-resource-id-1.md)
- [Collect Deltas FHIR® Datasets](https://docs.particlehealth.com/reference/get_deltas-r4-patient-particle-patient-id-everything-1.md): Returns a FHIR® Bundle of changed resources for the patient.
- [Search for FHIR® resources.](https://docs.particlehealth.com/reference/get_deltas-r4-resource-type-1.md): Searches deltas for a specific resource type
- [Read a specified FHIR® resource.](https://docs.particlehealth.com/reference/get_deltas-r4-resource-type-resource-id-1.md): Reads a specific changed resource.
- [Collect Deltas Flat Datasets](https://docs.particlehealth.com/reference/get_deltas-flat-particle-patient-id-1.md): Returns Flat datasets changed since `_since`.
- [List Queries](https://docs.particlehealth.com/reference/get_api-v1-queries-1.md): Lists queries you’ve created.
- [Get Query](https://docs.particlehealth.com/reference/get_api-v1-queries-id-1.md): Returns status and result pointers for a query.
- [Download a zipped file of all results of query](https://docs.particlehealth.com/reference/get_api-v1-files-query-id-zip-1.md): Download a zip file
- [Create Query](https://docs.particlehealth.com/reference/post_api-v1-queries-1.md): Starts a one‑time network query using demographics.

- [Search Network Participants](https://docs.particlehealth.com/reference/get_api-v1-networkparticipants.md): Search for healthcare organizations participating in Particle's connected networks.
- [Search Network Participants](https://docs.particlehealth.com/reference/get_api-v1-networkparticipants-state-state.md)
- [Search Network Participants](https://docs.particlehealth.com/reference/get_api-v1-networkparticipants-zipcode-zip.md)
- [Get Patient Signals Cohort](https://docs.particlehealth.com/reference/get_api-v1-patients-signalscohort.md): Retrieve the list of patients currently enrolled in Signal monitoring for your project.
- [Get Patient Signals](https://docs.particlehealth.com/reference/get_api-v1-patients-id-signals.md): Retrieve the Signal alert history for a specific patient.
